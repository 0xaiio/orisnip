# 作品简介 · 一刀万象

## 一句话

**折一折，剪一刀，亲手揭开由计算几何创造的万千纸艺世界。**

备选：一张纸，一把剪刀，让数学与艺术在展开的瞬间相遇。

- 中文：**一刀万象**

## 创作灵感

小时候剪窗花，大人只说"对折三次，随便剪几刀"。我们照做，却从不知道为什么剪出来是这个样子。

后来知道这件事有个名字——**Fold-and-Cut**。Erik Demaine 等人在 1999 年证明：
任何由有限条直线段构成的目标图形，都能通过先把纸折叠成某个平折状态、再沿一条直线剪一刀得到。
定理保证了表达力，却没有告诉你该怎么折。

于是有了这个作品：把那条"为什么"变成可以亲手拖动的东西。
你不需要先学几何——你只需要折一下，剪一刀，然后看着它展开。

---

## 核心玩法

```
折叠 → 剪切 → 展开 → 惊喜
Fold  →  Cut  → Unfold → Wonder
```

1. **选折法**：不折 / 左右对折 / 上下对折 / 两次正交（两种层序）/ 对角对折。
2. **调切线**：在折叠后的纸包上拖动唯一的一条直线。可以整体平移，也可以拖端点改角度。
3. **下刀**：刀锋沿直线扫过，被剪掉的部分用斜线阴影标出。
4. **展开**：纸一层层打开，每一帧都由真实变换求出。
5. **比对**：与实际目标图案比较 IoU，得到"完全吻合 / 通关 / 非常接近 / 还差一点"。

## 数学原理

**每一次折叠，都是给纸上的每个点换一次坐标。**

纸面坐标 $\mathbf{p}$ 与纸包坐标之间，每个面片都相差一个等距变换：

$$
T(\mathbf{p}) = M\mathbf{p} + \mathbf{t},\qquad M\in O(2)
$$

折叠 = 在等距群内左乘一个反射 $R_L$；展开 = 把每个面片的原始区域读回来。

一刀 = 一个半平面 $H$。剪切就是把每个面片裁剪成 $T^{-1}\big(T(P_i)\cap H\big)$。
展开就是把这些面片求并。

于是"折两次、沿 $u+v=d$ 剪掉靠近原点的一角"为什么得到菱形孔洞，
可以一行推导出来：

$$
u=|x|,\ v=|y| \;\Longrightarrow\; u+v<d \iff |x|+|y|<d
$$

而 $|x|+|y|<d$ 正是菱形。剩余面积 $4-2d^2$——这条等式被写进了测试，
`d` 取 0.2/0.35/0.5/0.65/0.8 时都必须逐点吻合。

## 创新价值

| 常见做法 | 本作品 |
|---|---|
| 把一张对称图形镜像 N 次 | 每个面片带一次真实等距变换，展开是它的逆映射 |
| 预设几张漂亮结果图 | 关卡目标由合法解**正向生成**，构造上必有解 |
| 用像素相似度判分 | IoU + 对称差面积，确定性、可复现 |
| 动画是"看起来像"的装饰 | 每一帧由 `partialFold` 求出，末帧与几何结果逐位一致 |
| 大模型直接画图 | 模型只输出受限参数，图案仍由引擎计算 |

最重要的一条：**这个应用里没有一张预制成品图**。你看到的每个图案，
都是当前参数算出来的。

## 用户体验

- **打开即玩**：无需注册、无需登录，首页就有一个正在运行的折叠-剪切-展开循环。
- **20 秒闭环**：第一关只需要拖动一条线，点一次"剪一刀"。
- **失败也有信息**：不是"错误"，而是"你在中心多剪掉了约 1.200 的纸，
  孔洞偏大：把剪切线向折角方向平移一点"。
- **可带走**：SVG（矢量、可再编辑）、PNG 2048、1200×1500 分享卡。
- **可继续**：作品只存参数，几百字节，随时回来改。

## AI 使用情况

**定位：设计助手，不是画师。**

用户写一句自然语言（"中秋主题的对称窗花，有月亮和花瓣"），模型把它翻译成
引擎能执行的参数：折法枚举、1–4 条切口的 `corner/size/angle/flip`、两种颜色。

模型没有能力画任意曲线、文字或写实图形，也**不被允许**声称某个图案"可以一刀剪出"。
所有输出先经 JSON Schema 校验，再经几何合法性校验，任何一步不通过就丢弃并提示，
不会渲染成"看起来像"的东西。

**当前状态（必须如实说明）**：代码已完成完整调用链（system prompt、流式累积、
错误分类、限流与降级），但本次部署**没有可用的云端模型凭据**，
因此页面显示"运行时模型未接入"，生成按钮会如实返回未接入状态，
同时提供 5 套由代码生成的参数化模板供使用。**没有伪造任何 AI 输出。**
