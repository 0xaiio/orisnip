### 黄金用例（最关键的一条）

折两次 → 沿 $u+v=d$ 剪掉靠近原点的一角 → 展开：

```
d = 0.55
期望面积     = 4 − 2·0.55² = 3.395
实际面积     = 3.395          (误差 < 1e-8)
IoU          = 1              (误差 < 1e-8)
对称差面积   < 1e-9
孔洞数       = 1
中心 (0,0)                 → 不在纸上 ✔
(d·1.15, 0)                → 在纸上   ✔
(d, d)                     → 在纸上   ✔
```

并对 d = 0.2 / 0.35 / 0.5 / 0.65 / 0.8 逐点验证面积单调性与解析值吻合。

## 六、关于发布

本次执行环境**没有提供 WorkBuddy 的站点发布工具**（`workbuddy_sites_deploy` 返回
"not available in the current environment"），因此：

- **没有产生任何公开访问链接**；
- 没有把 `localhost` 当作参赛链接；
- 也没有虚构"已发布"状态。

已准备好可立即发布的状态：

```
dist/                 生产构建产物（相对路径 base，可直接静态托管）
index.html            入口
```

发布步骤（在有发布能力的环境中）：

1. 打开本项目目录，执行 `npm run build`（已通过）。
2. 使用 WorkBuddy 的「网站应用发布」能力，指向项目根目录。
3. 发布后用浏览器实际访问，逐项核对第 18 节清单。
4. 把正式 HTTPS 链接回填到《参赛报名信息.md》。

发布前的本地验证已全部通过（构建、测试、8 路由浏览器验收）。
