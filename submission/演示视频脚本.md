# 演示视频脚本（30–60 秒）

**目标**：在一个信息流里说清"简单操作 → 复杂结果"的反差。
**总时长**：58 秒
**画幅**：1920×1080，浏览器满屏，隐藏书签栏与标签页
**背景音乐**：无（或极轻的纸质摩擦音效）；全部解说用字幕，便于静音观看

## 关键镜头要求

1. **0:09 的刀锋**：必须拍到"斜线阴影"标出的待剪区域，这是"所见即所得"的证据。
2. **0:14 的展开**：不能剪辑成淡入淡出，要拍到纸张一层层打开的过程（约 1.8 秒）。
3. **0:30 的结算**：IoU 数字必须清晰可读（100%），这是"真实评分"的证据。
4. **0:44 的导出**：拍下载完成的瞬间 + 打开文件，证明不是截图。

## 录制方式

```bash
npm run build && npm run preview   # 或 npm run dev
```

- 录屏工具：系统自带录屏 / OBS，1920×1080，60 fps
- 浏览器：Chrome 或 Edge，窗口 1440×900，缩放 100%
- 提前把 localStorage 清空，保证进度从 0 开始（画面更干净）
- 首页动画周期约 9 秒，建议从动画起点开始录，取前 24 秒
- 关卡的"标准解"可以先用「查看解答」定位，再手动微调，动作更自然

## 若 AI 功能可用的替换方案

如果部署环境接入了真实模型，把 0:44–0:50 换成：

> 在 AI 灵感设计师输入「中秋主题的对称窗花，有月亮和花瓣」→ 设计参数返回 →
> 图案生成 → 点击「在工坊中继续」。

并在字幕加一行："模型只输出参数，图案仍由几何引擎计算。"

**当前部署未接入模型，因此成片不要出现 AI 生成画面**，避免与事实不符。
