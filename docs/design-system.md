# 设计系统

一份简短的、可执行的视觉规范。它的作用是让新增页面不必重新发明排版。

## 1. 定位

**现代数字艺术 + 中国传统剪纸 + 日本折纸的几何美学 + 精致的科学展览。**

要避免的三件事：普通 SaaS 后台的矩形卡片堆叠、AI 产品常见的紫色渐变、
用大段文字代替可视化交互。

## 2. 色彩

| 令牌 | 值 | 用途 |
|---|---|---|
| `--paper` | `#F8F3E9` | 页面底色（宣纸白） |
| `--paper-2` | `#F1E9DA` | 次级区块、页脚 |
| `--paper-3` | `#E9DFCC` | 进度条底、分隔 |
| `--ink` | `#242725` | 主文字（墨） |
| `--ink-soft` | `#4A4F4B` | 正文 |
| `--ink-mute` | `#7C817B` | 辅助信息、标签 |
| `--red` | `#B93645` | 纸的主色、主按钮、强调 |
| `--red-bright` | `#D84A49` | 悬停态、节日模板 |
| `--red-deep` | `#8E2531` | 悬停加深、切口描边 |
| `--gold` | `#C9A46A` | 金线、分隔、提示 |
| `--jade` | `#378C86` | 次级强调（镜像点、几何模板） |
| `--line` | `#E0D6C4` | 1px 分隔线 |

**使用比例**：纸白 80%，墨 12%，红 6%，金/青 2%。
红色是"纸"本身的颜色，不是装饰色——大面积红只出现在纸张图形上。

## 3. 字体

| 角色 | 字体栈 | 用法 |
|---|---|---|
| 展示 | `Songti SC / STSong / Noto Serif SC / SimSun / Georgia` | 标题、作品名 |
| 正文 | `PingFang SC / Microsoft YaHei / system-ui` | 段落、按钮 |
| 数据 | `SFMono / Consolas` | 坐标、面积、比例、eyebrow 标签 |

字号阶梯：`display-hero` clamp(3.4–7.4rem) → `display-1` clamp(2–3.2rem) →
`display-2` clamp(1.35–1.9rem) → 正文 0.84–0.92rem → 辅助 0.68–0.78rem。

中文标题一律加字距（`letter-spacing: 0.04–0.1em`），这是宋体排版的呼吸感来源。

## 4. 间距与版心

- 版心 `max-width: 1240px`，左右内边距 `clamp(1.1rem, 4vw, 3rem)`
- 区块垂直节奏：`py-10 ~ py-24`，靠留白而非分割线分组
- 卡片圆角统一 4px（纸的折角是尖的，圆角过大会失去"纸"的语义）

## 5. 组件

- **`.btn-primary`**：红底米白字，仅用于每屏一个主行动
- **`.btn-outline`**：墨色描边，用于次行动
- **`.btn-ghost`**：线框，用于工具类操作
- **`.chip`**：胶囊标签/筛选，`[aria-pressed=true]` 即选中态（墨底）
- **`.sheet`**：白纸卡，1px 暖色描边 + 极轻投影
- **`.sheet-quiet`**：半透明纸卡，用于不需要强调的说明块

## 6. 纸张的视觉规则

纸张图形必须满足：

1. 有轻微的明暗渐变（`linear-gradient` 叠加），不能是纯色块；
2. 有 1px 深色描边，表达纸张厚度；
3. 折痕用虚线，切口用更粗的红虚线 + 白色光晕；
4. 被剪掉的部分用 45° 斜线阴影（hatch）标示，不用纯色遮盖；
5. 分享卡上的图案不带投影（印刷语境），屏幕上的带投影。

## 7. 动效

| 场景 | 时长 | 缓动 |
|---|---|---|
| 折叠 / 展开单层 | 0.5–0.6 s | `cubic-bezier(0.22, 0.61, 0.24, 1)` |
| 刀锋扫过 | 0.56 s | 同上 |
| 结果显现 | 0.9 s | 同上，带轻微放大 |
| 悬停位移 | 0.35 s | 同上 |

所有动效在 `prefers-reduced-motion: reduce` 下退化为即时状态切换。
动画只表达真实状态变化，不用于"显得高级"。

## 8. 无障碍

- 主色 `#B93645` 在 `#F8F3E9` 上的对比度为 5.6:1，满足 AA
- 状态不能只靠颜色：通关用"✓ + 已通关"文字，选中用墨底反色
- 所有图标按钮都有 `aria-label`
- 画布提供 `role="slider"` 与方向键微调
- 焦点环统一 2px 红环 + 3px 偏移，不使用 `outline: none`
