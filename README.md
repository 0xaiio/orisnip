# 一刀万象 · Orisnip

> 一张纸，千种可能；一把剪刀，万象展开。
> *One Cut, Infinite Wonders — a computational paper-art laboratory.*

一个可以真正玩的数字折纸 / 剪纸实验室：把一张虚拟方纸折起来，沿一条**连续的直线**剪一刀，
再逐层展开，看同一条直线如何长成对称的窗花。

所有图案来自确定性的二维折纸几何计算——不是预制图片，也不是"看起来对称"的装饰性 SVG。

---

## 它解决什么问题

大多数"剪纸生成器"只做了一件事：把一张对称图形镜像 8 次。
但真实的折剪有严格的数学约束：**折叠是等距变换，展开是它的逆映射，而一刀只能是一条直线**。

Orisnip 把这三件事做成一个可验证的引擎：每一层纸都记录一次 `sheet → packet` 的正交变换，
剪刀在折叠后的纸包上走一条直线，展开就是把每层纸的变换读回去再做布尔并。
于是"折两次 + 斜剪一刀 = 中心菱形孔洞"这种结果，是**算出来的**，不是画出来的。

## 核心能力

**几何引擎**（`src/geometry/`，纯函数、零 DOM 依赖）

- 刚体变换：复合、求逆、反射、部分折叠（`p → p − (1−k)(n·p)n`）
- 六种折叠方案：不折 / 左右 / 上下 / 两次正交（两种层序）/ 对角
- 单条直线切割，含零长度、不相交、切空三类合法性拒绝
- 展开：面片 `sheetRegion` 布尔并，正确表达孔洞与多连通分量
- 逐层展开时间轴：每一帧由真实变换插值得到，末帧与几何结果逐位一致

**游戏**（`src/game/`）

- 目标由 `unfold(applyCut(packet, solution))` 正向生成 → 构造上必有解
- 评分：IoU + 对称差面积比，确定性、可复现
- 失败反馈由几何差异反推位置（"你在右上方多留了 0.18 的纸"）
- 关卡进度本地保存

**工坊与导出**（`src/services/`）

- 作品只存参数（折法 + 切口 + 两色），几百字节，重载即重算
- SVG：真实矢量路径、`fill-rule="evenodd"` 表达孔洞、无外链、无位图
- PNG：2048 × 2048 高清导出
- 分享卡：1200 × 1500 海报版式

## 六个不变量

这些是代码里的硬约束，也是测试断言的依据：

1. 折叠前后，所有面片 `sheetRegion` 的并集恒等于原纸。
2. 每个面片的变换行列式为 ±1（等距变换）。
3. 剪一刀之后，纸张面积不会增加。
4. 展开结果的每一个顶点都落在原纸范围内。
5. 同一输入必然得到同一输出（无随机数、无时间依赖）。
6. 展开动画的最后一帧，与 `unfold()` 的并集结果重合。

## 已知边界

这些边界是刻意选择的，不是未完成的缺口：

- 折法只有六种预设，**不支持任意折痕**。引擎本身是通用的，但 UI 只暴露经过验证的方案。
- 剪一刀模式严格限制为"完全折叠后的单条连续直线"，不支持曲线或折线。
- 工坊支持多刀，因此产出的是"多次折叠 + 多次直线剪裁"可复现的图案，
  不会声称它是"一刀剪出"的。
- AI 功能需要云端模型环境；未配置时界面显示"未接入"，不产生伪造输出。
